# Oma Darzi — Tailored Jeans & Shirts

A simple static site for a tailoring business with an on-device AI body measurement tool using MediaPipe Pose.

## Local development

- Serve locally: `python3 -m http.server 3000 --directory .`
- Open: `http://localhost:3000`

## AI Measurement
- Uses your webcam and runs entirely in the browser
- No video is uploaded or stored
- Estimates: shoulder width, chest/waist circumferences, hips, inseam

## Deployment
This site is configured for GitHub Pages. Once pushed to `gh-pages`, it will be available at:

- https://<your-username>.github.io/OmaDarzi/

Replace `<your-username>` with your GitHub handle.
